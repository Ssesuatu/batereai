# Security policy

Batereai reads local data from T3 Code and can open a short-lived session on the local T3 Code
server, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's
[private vulnerability reporting](../../security/advisories/new) for this repository instead.

Include the Batereai version (`Batereai.exe` → Properties → Details), your T3 Code version, and steps
to reproduce. You should get a reply within 7 days.

## Supported versions

Only the latest release receives fixes.
